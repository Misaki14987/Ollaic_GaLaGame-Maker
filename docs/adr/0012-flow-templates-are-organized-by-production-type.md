# Flow Templates Are Organized by Production Type

V2 organizes Flow Templates around Production Type rather than Story Subject: subjects like campus or cyberpunk configure style and setting, while types like mystery, romance routes, multi-ending, demo, or long-form work can change the production workflow. This keeps the user-facing brief natural while letting the system add specialized Steps such as clue tracking, route planning, ending reachability, or consistency review when the production type requires them.

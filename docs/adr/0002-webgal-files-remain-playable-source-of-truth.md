# WebGAL Files Remain the Playable Source of Truth

V2 keeps the Project's WebGAL files, assets, and character records as the source of playable content while StoryPlan records generation intent, context, step outputs, and run history. This avoids creating a second competing story database and lets FlowBoard become the V2 entry point without invalidating existing scene editing, asset management, previews, exports, and change-set safety.

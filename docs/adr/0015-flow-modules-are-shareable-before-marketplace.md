# Flow Modules Are Shareable Before Marketplace

V2 treats Flow Templates and Flow Modules as shareable production recipes, but the core product should first support local authoring, import, export, and reuse before committing to an integrated Flow Marketplace. This keeps the Production Studio extensible around reusable workflow knowledge while deferring marketplace-specific work such as discovery, ratings, review, trust signals, and update distribution until the recipe format and user demand have proven themselves.

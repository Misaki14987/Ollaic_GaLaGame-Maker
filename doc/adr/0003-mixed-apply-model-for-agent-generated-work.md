# Mixed Apply Model for Agent Generated Work

V2 uses a mixed apply model: planning and early content Steps produce staged output, while Run to Playable may let approved write Steps update the Project automatically with snapshots, diffs, and rollback records. This preserves the current user-confirmed change-set safety model for exploratory generation while still allowing a true end-to-end path when the user intentionally asks the Agent Flow to produce a playable build.

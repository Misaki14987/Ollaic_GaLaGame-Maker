# V2 Is an AI Galgame Production Studio

V2 positions Ollaic as an AI galgame Production Studio: users produce WebGAL visual novels through reusable Agent Flows, then inspect, repair, and refine the resulting project with the existing editors. This chooses a higher-level production workflow over treating AI as a copilot panel inside a WebGAL IDE, while still keeping WebGAL files as the playable source of truth.

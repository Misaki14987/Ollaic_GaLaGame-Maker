# ollaic-ui

This directory contains the Tauri desktop application: React/Vite source in `src/` and the Rust backend in `src-tauri/`.

Run commands from the repository root, not from this directory:

```bash
pnpm install --frozen-lockfile
pnpm tauri:dev
```

See [root README](../../README.md) for the full setup, verification, and troubleshooting guide.
